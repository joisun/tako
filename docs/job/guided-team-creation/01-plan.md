# 实施计划

1. 复用现有 Runtime 执行器，持久化一次组队规划及 Session 引用，支持状态查询、取消、失败和重启后中断，不增加独立执行器。
2. 从本地和已启用市场目录检索有界候选，保留实际定义快照；规划输出仅建议已有能力范围内的客户端、模型、effort，确认创建时重新校验。
3. 原子创建团队及成员，保留源定义、职责、头像和执行配置；创建并开始沿用现有用户消息及 Leader 工作流程，幂等防止重复建队或重复启动。
4. 用现有 shadcn 对话框和字段实现输入、生成状态、团队草案编辑；实际入口仍使用共享 43130。
5. 隔离验证规划、取消/失败、模型能力、市场安装、原子性和幂等，再进行实际低 effort 规划与浏览器验证；更新直接相关文档。
